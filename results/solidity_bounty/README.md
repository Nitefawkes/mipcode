## 4. Upstream Validation & Filed Technical Reports

- **Independently corroborated upstream (found on pre-fix snapshot; fixed separately by maintainer):**
  - `WormholeGatewayAdapter._wormholeChainId`: Removed independently by `@james-toussaint` in [`OpenZeppelin/openzeppelin-community-contracts#276`](https://github.com/OpenZeppelin/openzeppelin-community-contracts/pull/276).
- **Submitted upstream by us (`@Nitefawkes`):**
  1. [`OpenZeppelin/openzeppelin-community-contracts#321`](https://github.com/OpenZeppelin/openzeppelin-community-contracts/issues/321) — Reports `WormholeGatewayAdapter._sendMessage` (`contracts/crosschain/wormhole/WormholeGatewayAdapter.sol:327-335`) passing `targetChain` in both the destination (`L328`) and `refundChain` (`L333`) argument slots of `sendPayloadToEvm`.
  2. [`OpenZeppelin/openzeppelin-community-contracts#277 (comment)`](https://github.com/OpenZeppelin/openzeppelin-community-contracts/pull/277#issuecomment-6907989982) — Documents that `Outbox[] memory outbox` in `ERC7786OpenBridge.sendMessage` (`L126–L149`) retains zero-initialized `(address(0), bytes32(0))` entries on non-reverting `catch` paths before `OutboxDetails` emission.
  3. [`Strata-Markets/contracts#20`](https://github.com/Strata-Markets/contracts/issues/20) — Reports unread `tokenAmount` in `MidasStrategy.withdrawInner` (`L246`) and unread `private uint decimalsInternal` in `IntegrationsLens.sol:29`.

## 5. CLI Usage

```bash
# Audit a Solidity directory or single contract
mip-delta --audit-solidity --root contracts/ --fail-on-findings

# Compare vulnerable vs patched contract snapshot
mip-delta --before Vault_v1.sol --after Vault_v2.sol --json

# GitHub Actions warning annotations
mip-delta --audit-solidity --root contracts/ --format github --fail-on-findings
```
