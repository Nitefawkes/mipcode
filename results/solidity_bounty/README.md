## 3. CLI Usage

```bash
# Audit a Solidity directory or single contract
mip-delta --audit-solidity --root contracts/ --fail-on-findings

# Compare vulnerable vs patched contract snapshot
mip-delta --before Vault_v1.sol --after Vault_v2.sol --json

# GitHub Actions warning annotations
mip-delta --audit-solidity --root contracts/ --format github --fail-on-findings
```
